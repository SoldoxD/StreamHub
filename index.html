StreamHub

Kodi 21+ video add-on. Live TV, movies, series with xstream-style multi-host picker.

Install

  1. In Kodi: Settings → System → Add-ons → Unknown sources → ON
  2. Settings → File manager → Add source → paste:
    https://soldoxd.github.io/StreamHub/
    Name it streamhub.
  3. Settings → Add-ons → Install from zip file → streamhub → plugin.video.streamhub → the newest plugin.video.streamhub-*.zip

Done. The addon appears in Add-ons → Video add-ons → StreamHub. From then on it auto-updates — see below.

Auto-update

A small background service inside the addon checks this page once a day and pulls new versions automatically.

  • Settings → UPDATES → Auto-Update (on by default) — installs without asking
  • Bei jedem Kodi-Start auf Updates pruefen (on by default) — check at startup
  • Jetzt nach Update suchen — manual trigger anytime

After an update is installed, restart Kodi for the new code to take effect.

Settings

Every source is on by default — StreamHub works out of the box, no setup needed. The settings screen has a Basic / Advanced / Expert switcher (bottom-left of Kodi's settings window).

  • Basic — the three that matter: Preferred language (default German; streams in your language are sorted first), Always pick host manually, and Auto-Update.
  • Advanced — turn individual sources off (vavoo, livetv.sx, 67movies, ramoflix, filmpalast, kinox), stream quality cap, HLS player, and cache/maintenance actions.
  • Expert — debug logging and the optional STALKER IPTV portal (off by default).

DLHD (DaddyLive) is always enabled — it has no toggle. Its channels are merged into the normal channel list (duplicates of a vavoo channel become one entry where you pick the source) and its sport events are merged with livetv.sx under Sport.

What's inside

  • Live TV: VAVOO + DaddyLive (DLHD with soccer schedule), optional Stalker
  • Movies / Series with xstream-style multi-host picker across VAVOO, 67movies, ramoflix, filmpalast, kinox — search runs in parallel, results are deduped by title, the host list merges every source that has the title.
  • Self-contained: vendored urllib HTTP client; works on a fresh Kodi without script.module.requests, resolveurl, dateutil, or infotagger. Uses them if present.

Updating

Re-run steps 2 & 3 of Install with the new zip filename. Kodi will overwrite the existing install while keeping your settings.
