StreamHub

Kodi 21+ video add-on. Live TV, movies and series with xstream-style multi-source host selection.

Install in Kodi

  1. Settings → System → Add-ons → Unknown sources → ON
  2. Settings → File manager → Add source → paste: https://soldoxd.github.io/StreamHub/ Name it streamhub.
  3. Settings → Add-ons → Install from zip file → streamhub → repository.streamhub → repository.streamhub-1.0.0.zip
  4. Settings → Add-ons → Install from repository → StreamHub Repository → Video add-ons → StreamHub → Install

Future updates come automatically through Check for updates.

Files

  • addons.xmlrepository manifest
  • addons.xml.md5checksum
  • repository.streamhub-1.0.0.ziprepo addon
  • plugin.video.streamhub-2026.06.09.zipvideo addon (direct install)

What's inside

  • Live TV: VAVOO + DaddyLive (DLHD) with soccer schedule, optional Stalker
  • Movies / Series with multi-host picker: VAVOO + 67movies + ramoflix + filmpalast + kinox
  • Self-contained: vendored urllib HTTP client; works on a fresh Kodi without script.module.requests, resolveurl, dateutil, or infotagger (used if present, not required).
